# Git workflow

- Commit to `main`. Use a branch for a large or risky change.
- Use the commit message format `<type>(<scope>): <description>` ([Conventional Commits](https://www.conventionalcommits.org/)).
  - Types: `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `build`, `chore`.
  - Write the description in the imperative mood. Use lowercase. Do not end it with a period.
  - Mark a breaking change with `!` or with a `BREAKING CHANGE:` footer.
